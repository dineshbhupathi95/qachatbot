
# qachatbot

# 📄 Document QA ChatBot

This Streamlit app uses a flan-t5-large language model to answer questions based on the **Documents**. It allows you to interactively query the manual and get precise, context-based answers.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/dineshbhupathi95/qachatbot.git
cd qa-bot

###2. Install dependencies
pip install -r requirements.txt


###3. Run the application
streamlit run main.py
